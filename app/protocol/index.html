HOXO LEND · STELLAR TESTNET

Protocol

Hoxo Lend is an independent Soroban/Rust lending system, not Maddeth's Solidity contracts running against another RPC.

Development preview — not deployed. No verified Hoxo Lend lending pools, deposits, yields, or user positions exist in the active registry. This is not a live money market.
01 / ASSETS

Stellar asset layer

Native XLM and verified issued USDC through Stellar Asset Contracts (SAC). Explicit token amounts and issuer checks.

02 / MARKETS

Credit accounting

Supply and borrow indices, kinked rates, reserve factor, caps and deterministic debt accounting.

03 / ORACLES

Price integrity

Independent, permissioned sources; timestamps, confidence, staleness and fail-closed risk actions.

04 / RISK

Liquidations

Collateral limits, health factor, liquidation penalty, reserve absorption and solvency invariants.

05 / RWA

Isolated credit

Issuer permissions, lender controls, debt caps, maturity/default handling and evidence.

06 / CLIENT

Wallet + receipts

Freighter, supported Stellar SDK, simulated auth trees and verifiable Testnet transaction hashes.

Migration boundary

The old Maddeth implementation is preserved only in legacy/maddeth-kub/. It is not linked from the active application and must never be deployed to Stellar. No live lending claim is made before verified Soroban deployments.
